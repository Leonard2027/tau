# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those
roles to the actual GitHub label strings used in this fork's issue tracker.

| Canonical role    | GitHub label        | Meaning                                  |
| ----------------- | ------------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`      | Maintainer needs to evaluate this issue  |
| `needs-info`      | `needs-info`        | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent`   | Fully specified, ready for an AFK agent  |
| `ready-for-human` | `ready-for-human`   | Requires human implementation            |
| `wontfix`         | `wontfix`           | Will not be actioned                     |

When a skill mentions a canonical role, use the corresponding GitHub label from
this table in `Leonard2027/tau`.

Every triaged issue should carry exactly one category label (`bug` or
`enhancement`) and exactly one state label from this table. If state labels
conflict, stop and ask the maintainer before changing them.

Edit the GitHub label column if this fork adopts a different label vocabulary in
the future.
