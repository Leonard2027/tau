循环何时继续，何时停止？

把 Card 06/07 的退出条件拼成一张完整控制流图：has_more_tools、follow_ups、max_turns、错误分支四条路径，各自的出口在哪。

先预测 源码切片 路径练习 完整路线

0–3 分钟：先预测完整出口

你已知道 has_more_tools = bool(calls) 决定内层循环是否继续，follow_ups 决定外层是否开新 turn。还有两条路径你没细看：

  1. 如果 turn > max_turns（模型一直在调工具，超限了），loop 会怎样收尾？
  2. 如果 assistant 的 stop_reason 是 "error" 或 "aborted"，loop 会怎样收尾？

提示：两条都不是走 break。回忆 Card 06 提过"出错则提前 return"。

3–10 分钟：读完整控制流

src/tau_agent/loop.py:85–168

两条提前 return 的收尾

# 路径 A：max_turns 超限（loop.py:99–107）
if max_turns is not None and turn > max_turns:
    error = _error_message(model, f"Agent stopped after max_turns={max_turns}")
    messages.append(error); new_messages.append(error)
    yield MessageStartEvent / MessageEndEvent   # 一条 error 消息
    yield TurnEndEvent(message=error)
    yield AgentEndEvent(messages=new_messages)
    return

# 路径 B：模型报错 / 中断（loop.py:134–137）
if assistant.stop_reason in {"error", "aborted"}:
    yield TurnEndEvent(message=assistant)
    yield AgentEndEvent(messages=new_messages)
    return

两者都不再检查 follow-ups，直接结束整个 run。区别：A 会生成一条 AssistantMessage(stop_reason="error", error_message=...) 并写回历史；B 复用模型自己的错误/中断消息。

主循环：两个独立判定

while True:                              # 外层：run 是否继续
    has_more_tools = True
    while has_more_tools or pending:      # 内层：turn 是否继续
        ... 一次模型调用 + 执行它的工具 ...
        has_more_tools = bool(calls)
        if stop_reason in {error, aborted}: return     # 路径 B
    follow_ups = tuple(...)
    if follow_ups: pending = follow_ups; continue      # 开新 turn
    break                                # 无 follow-up → 正常结束
两个判定解耦：has_more_tools 是"模型是否还想要工具"（模型驱动），follow_ups 是"产品是否追加输入"（产品驱动）。max_turns 是外部的安全上限（防失控循环）。

10–14 分钟：为四条路径找出口

下面四种情况，各自从哪条出口结束？用 A（max_turns）、B（error/aborted）、C（break 正常）、D（continue 开新 turn）标注：

  1. 模型正常给出文本回答，用户没有 follow-up。
  2. 模型一直在调工具，turn 超过 max_turns。
  3. 模型报错（stop_reason="error"）。
  4. 模型给出回答，用户通过 harness 插入了 follow-up。
回答后展开参考答案
  1. C —— has_more_tools=False，无 follow-up，break（loop.py:166）。
  2. A —— turn > max_turns，生成 error 消息，return（loop.py:99–107）。
  3. B —— stop_reason="error"，直接 return（loop.py:134–137）。
  4. D —— follow_ups 非空，continue 回外层开新 turn（loop.py:162–165）。

注意：A 和 B 都不再检查 follow-ups——run 已决定终止。

14–15 分钟：一句话检索

内层 while has_more_tools or pending 由 ______ 驱动是否继续；外层由 ______ 决定是否开新 turn；max_turns 是 ______；模型报错/中断走 ______ 出口（不经过 break）。
面试表达：agent loop 的停止由三个独立机制共同决定——模型是否还要工具（内层）、产品是否追加输入（外层）、外部安全上限（max_turns）。错误与超限是"立即终止"，不等待产品补充输入。
