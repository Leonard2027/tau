Micro lesson 02 · tau_agent · About 15 minutes

一次工具调用怎样表示成有序消息？

本节只回答一个问题：用户提问、助手请求工具、工具返回、助手作答，怎样表示成 AgentMessage 与 content blocks？

先预测 源码切片 排序练习 完整路线

0–3 分钟：先画四步历史

暂时不要看答案。用户说“读取 README.md 后告诉我项目名”，助手调用 read，工具返回文件内容，助手再回答。

预测：历史里会有哪四条顶层消息？其中“调用 read”是独立消息，还是某条消息内部的 content block？

3–10 分钟：只读消息模型

src/tau_agent/messages.py:58–95

Content blocks

先分清 block 和 message

TextContent、ThinkingContent、ImageContent 与 ToolCall 都是内容块。ToolCall 用 id、name、arguments 描述一次请求。

User message

用户消息是顶层记录

UserMessage.role == "user"。它的 content 可以是字符串，也可以是 text/image blocks。

src/tau_agent/messages.py:116–178

Assistant message

工具调用嵌在有序内容里

AssistantMessage.content 是有序 blocks 列表；tool_calls 只是从这份列表中筛出 ToolCall。请求工具时，stop_reason 是 "toolUse"。

Tool result message

工具结果另占一条顶层消息

ToolResultMessage.role == "toolResult"。它用 tool_call_id 指回发起请求的 ToolCall.id。

src/tau_agent/messages.py:235–244

边界：AgentMessage 是按 role 区分的顶层消息联合。它包含 AssistantMessage 和 ToolResultMessage，但不直接包含 ToolCall；后者是 assistant content block。

10–14 分钟：排序并连线

把 A–D 排成历史顺序，并回答：哪个字段把工具请求与结果连起来？

  1. A — AssistantMessage(content=[TextContent("项目名是 Tau")], stop_reason="stop")
  2. B — ToolResultMessage(tool_call_id="call-7", tool_name="read", content=[...])
  3. C — UserMessage(content="读取 README.md 后告诉我项目名")
  4. D — AssistantMessage(content=[ToolCall(id="call-7", name="read", arguments={...})], stop_reason="toolUse")

请先把“顺序 + 关联字段”发给教师，再展开参考答案。

回答后展开参考答案

顺序：C → D → B → A。

关联：ToolResultMessage.tool_call_id == ToolCall.id，这里两边都是 "call-7"。

UserMessage
→ AssistantMessage(content includes ToolCall, stop_reason="toolUse")
→ ToolResultMessage(tool_call_id matches ToolCall.id)
→ AssistantMessage(final text, stop_reason="stop")

14–15 分钟：一句话检索

一次工具调用不是独立的顶层消息，而是 ______；工具返回则是 ______，两者通过 ______ 对应。
完成标准：能从空白处复述四条消息的顺序，并解释为什么 ToolCall 与 ToolResultMessage 不在同一层级。本节暂不讨论事件顺序或 loop 为什么继续。
