第一部分：tau_agent 可复用核心

01 · Public surface

tau_agent 对外暴露什么？

只读：tau_agent/__init__.py

练习：把导出项分成数据、协议、执行、会话四组。

02 · Messages

一次对话由哪些消息构成？

只读：messages.py 的 user、assistant、tool result 模型

练习：排列一次“提问→工具→回答”的消息历史。

03 · Provider protocol

核心怎样做到不知道具体模型厂商？

只读：provider.py:13–32

练习：列出 stream_response() 的输入与输出。

04 · Tool protocol

核心眼中的工具是什么？

只读：tools.py:21–105

练习：区分工具 schema、executor、result 与 renderer。

05 · Events

为什么 loop 不直接操作 UI？

只读：events.py:15–87

练习：把事件分成 agent、turn、message、tool 四层。

06 · Simple turn

没有工具调用时，一轮怎样结束？

只读：loop.py:44–85 与最终退出路径

练习：排出最短事件序列。

07 · Tool cycle

tool result 怎样回到模型上下文？

只读：loop.py:109–160, 225–282

练习：模拟一次 read 工具调用的两轮对话。

08 · Control flow

循环何时继续，何时停止？

只读：loop.py:85–168 的条件与出口

练习：为正常、错误、超限、follow-up 找出路径。

09 · Harness

AgentHarness 比裸 loop 多了什么？

只读：harness.py:61–100, 146–217

练习：区分算法状态、生命周期和消息队列。

第二部分：Agent 后端 / 平台面试与二次开发

从这里开始把前九节的源码模型用于本地 coding agent 的恢复、日志可观测性与 durable session 设计；分布式平台只作为本地主线掌握后的可选面试外推。

10 · Loop vs Harness

为什么同时需要无状态 loop 与有状态 harness？

证据：loop.py:44–168 与 harness.py:61–202

面试练习：比较纯 async generator 与状态编排对象的职责、测试性和部署边界。

11 · Reliability

取消或中断后，怎样保持对话协议完整？

证据：harness.py:146–190, 219–244

面试练习：解释 orphan tool call 为什么必须补成错误结果。

12 · Tool safety

授权、超时、隔离和错误归一化应该放在哪一层？

证据：tools.py 与 loop 的 before_tool_call/after_tool_call

面试练习：为高风险工具设计最小 policy gate。

13 · Streaming

provider stream 怎样沿本地链路到达 extension、session 与 TUI？

证据：provider_events.py → events.py → harness → CodingSession → TUI/CLI

练习：追踪一个 delta，区分 extension listener、主迭代路径、增量显示与最终持久化。

14 · State & durability

本地 runtime state 与 durable session log 怎样分工？

证据：harness.py queues/messages 与 session/ entries、tree/path replay、branch、compaction

微课：14 · 代码地图与 persist 快照 → 15 · 恢复 → 16 · 分支 → 17 · 压缩

速查：Durable session 术语表

练习：从 JSONL 日志恢复一条分支，并解释压缩后如何保留可审计历史。

15 · Secondary development · 规划中

怎样在现有 seam 上增加本地恢复或日志可观测性？

实践：使用 session entries、events、hooks 或 harness 扩展点完成一个小改动及测试。

面试产物：说明为何选择该 seam，以及如何保证日志可恢复、可关联且不耦合 provider/UI。

16 · Mock interview · 规划中

怎样设计一个可恢复、可观测的本地 coding agent？

综合：provider-neutral loop、工具执行、事件日志、session tree、恢复与压缩；最后可选说明如何扩展到平台。

练习：先完成本地架构陈述与故障恢复追问，再做可选的平台化权衡。

主线之外

tau_ai 的 Anthropic、OpenAI、Google 等具体 SDK/传输适配，以及 tau_coding 的 Textual/TUI 渲染细节，不进入当前主线。只有当具体二次开发或面试追问需要时，才按需读取相应切片。

每次只完成一张卡片。读到支线时先记下，不在当前 15 分钟内继续追。
